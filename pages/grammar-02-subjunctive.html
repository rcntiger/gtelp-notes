가정법매회 2~3문제

If절 동사의 시제만 보고 주절 동사 형태를 정하는 문제. 패턴 3개만 외우면 끝난다.

013가지 패턴

TYPE 1 — 가정법 과거 (현재 사실의 반대)
If + 주어 + 과거동사(were) ~, 주어 + would/could/might + 동사원형
지금 사실이 아닌 것을 가정. be동사는 인칭에 상관없이 were.
TYPE 2 — 가정법 과거완료 (과거 사실의 반대)
If + 주어 + had p.p. ~, 주어 + would/could/might + have p.p.
과거에 실제로는 그러지 않았던 일을 가정.
TYPE 3 — 혼합가정법 (과거의 일이 현재에 영향)
If + 주어 + had p.p. (과거) ~, 주어 + would/could/might + 동사원형 (현재)
If절은 과거완료인데 주절에는 now, today 같은 현재 시간 표현이 붙어 있다 — 이게 신호.

가정법 과거완료

O

혼합가정법 — 주절에 now / today 확인

O
If he had invested in the company then, he would be rich now.If절: 과거완료 / 주절: 동사원형 + now
함정 · 도치구문 (If 생략)
If가 생략되면 주어와 동사가 도치된다. Were she richer, she would travel more. / Had I known, I would have called you. 조동사(Were/Had/Should)로 문장이 시작하면 가정법 도치를 의심할 것.

wish + 주어 + had p.p.과거 사실과 반대되는 소망 ("~했더라면 좋았을 텐데")
