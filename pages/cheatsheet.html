신호어 총정리

시험장 들어가기 10분 전에 이 페이지만 훑는다. 왼쪽 신호어를 문장에서 찾으면 오른쪽이 정답이다. 문법 26문항 중 상당수가 이 표 안에서 해결된다.

01시제 — 시간 표현이 곧 정답

right now / at the moment→현재진행is/are + -ing
when + 주어 + 과거동사→과거진행was/were + -ing
when + 주어 + 현재동사 (미래 의미)→미래진행will be + -ing
since + 과거시점 / for the past 기간→현재완료진행have been + -ing
before / by the time + 과거동사→과거완료진행had been + -ing
by the time + 현재동사 & for + 기간→미래완료진행will have been + -ing

02가정법 — If절만 보면 끝

If + 주어 + 과거동사 / were→would + 동사원형
If + 주어 + had p.p.→would have p.p.
If + had p.p. & 주절에 now/today→would + 동사원형혼합가정법
Were / Had / Should로 문장 시작→If 생략 도치위 규칙 그대로 적용

03should 생략 — 앞 단어만 확인

suggest, recommend, insist, demand,
require, request, propose, order, urge→that + 주어 + 동사원형
It is necessary / essential / important /
imperative / crucial / vital / mandatory→that + 주어 + 동사원형

04준동사 — 앞 동사가 결정

want, hope, plan, decide, agree, expect,
refuse, promise, manage, afford, fail→to + 동사원형
enjoy, avoid, consider, finish, mind,
quit, deny, postpone, keep, admit, involve→동사원형 + -ing
전치사(in, on, at, of, for) 바로 뒤→동사원형 + -ing
look forward to / be used to / object to→동사원형 + -ingto는 전치사

05연결어 — 뒤에 오는 것이 결정

뒤에 명사(구)만 있음→전치사despite, because of, during
뒤에 주어 + 동사가 있음→접속사although, because, while

06관계사 — 뒤 문장의 완전성

뒤 문장에 주어·목적어가 빠짐→관계대명사who / which / that
뒤 문장이 완전함 + 선행사가 장소/시간→관계부사where / when
앞에 콤마(,)가 있음→that 절대 불가who / which만
선행사가 아예 없음→what

07시험장 행동 요령

  • 문법은 문장 전체를 해석하지 말고 빈칸 주변 신호어만 스캔한다
  • 선택지에 진행형이 하나뿐이면 대개 그것이 답이다
  • 한 문항에 30초 이상 쓰지 않는다 — 넘기고 나중에 돌아온다
  • 모르는 문항도 반드시 마킹한다 (오답 감점 없음)
  • 청취는 문제지에 메모가 허용되는지 시험 안내를 확인하고, 허용 범위 내에서 노트테이킹
